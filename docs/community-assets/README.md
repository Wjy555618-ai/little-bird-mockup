## 证据边界

所有宣传图只使用当前项目中的真实界面截图、正式 r3 样机或真实测试输出。宣传文案只覆盖已验证能力：选择样机、放入 Figma 选区或本地文件、缩放/移动/旋转/色彩调整、自由透视、粘贴回 Figma、导出 PNG、无需登录以及用户画面本地处理。

没有宣传不存在的样机数量、动画/3D/视频能力、付费权益或未验证性能。

## 发布前仍需确认

最终小鸟图形的公开发布权利仍应由决定人确认；本目录中的图标只是基于当前已确定小鸟形象制作的上架候选。

宣传图中的透明小鸟使用浅色表面专用制品（深色眼睛、鸟嘴和双腿）；插件深色顶栏使用另一份同几何制品（白色眼睛、鸟嘴和双腿）。不得跨场景混用。
