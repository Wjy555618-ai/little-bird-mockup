# 证据目录

本目录保存真实浏览器、真实 Figma 宿主、导出结果和发布门禁的原始附件。它用于回答“哪个准确构建在什么环境完成了什么任务”，不是产品截图素材库，也不是当前版本自动通过的证明。

## 有效性规则

- 每份证据只对其记录的构建指纹、素材 revision、测试场景和日期有效。
- 文件名中的 `DEV-*`、日期或场景名不能替代对应 JSON/报告中的字节摘要和断言。
- 代码、素材、目录、几何或构建变化后，旧证据继续保留作历史审计，但不得升级为当前版本结论。
- 正式发布证据必须由 `pnpm evidence:draft` 从准确 REL 包创建，并由 `pnpm evidence:check` 验证。
- 已淘汰品牌草稿不属于工程证据，已通过 `.gitignore` 排除。

## 内容分区

- 根目录：插件交互、视觉回归和真实宿主截图；历史文件保留原名，避免破坏已有报告引用。
- `asset-pipeline/`：素材候选、技术 QA、真实宿主导出和最终批次相关附件。
- `community-assets/` 位于 `docs/` 的独立目录：Figma Community 图标和宣传图源文件，不与质量证据混用。

证据数量和体积不是成熟度指标。新增附件必须服务一个明确门禁、报告或根因分析；没有可追溯用途的临时截图不得提交。
