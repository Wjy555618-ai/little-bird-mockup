# 样机工作室剩余缺陷验收矩阵（2026-10-29）

## 任务契约

- 主目标：在现有 Mockup 风格、三大 Tab 和本地/后续远程资产库架构不变的前提下，关闭 A–L 已知缺陷。
- 完成标准：A–L 均有当前构建的正常鼠标/键盘实操证据；浏览器与真实 Figma Desktop 关键路径通过；`pnpm build`、`pnpm check`、`git diff --check` 通过；已验证里程碑写入 Git。
- 不做：不新增产品功能、不重画另一套 UI、不以静态断言或构建成功替代交互验收、不把本地开发插件证据扩张为线上或 Community 发布证明。

## 探索性场景

1. 在 250% 预览倍率下进入裁切，再取消并切换样机，确认没有旧裁切框或控制点漂移。
2. 将样机拖到四个极限方向后切换三个 Tab，再执行适应与复位，确认 10% 可见约束和统一几何没有被模式切换破坏。

## 证据规则

- 只有正常鼠标/键盘操作后的可见结果计为通过；脚本求值只用于读取状态或量化几何。
- 每次修正后重新构建并从浏览器关键路径开始回归；Figma 验收必须重新打开开发插件确认加载最新构建。
- 失败项写明复现步骤、根因层级和修正后的复验结果；未实操项保持未通过。

## B 项根因与修正层级

问题不在 UI 控制点坐标，而在位图屏幕开口：软压缩边缘与局部孔洞使名义四边形之外仍残留色键像素，原有黑色底层在高倍率下从开口边缘露出。修正保持名义四边形作为唯一编辑几何，同时在渲染层增加受支撑四边形约束的有效色键行段填充、2 px 膨胀和无圆角 bleed underpaint。这样既关闭开口缝隙，也不改变普通编辑、裁剪和透视控制点的坐标基准。
