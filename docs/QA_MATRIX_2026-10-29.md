| 路径 | 必须实际操作 | 当前证据标准 |
| --- | --- | --- |
| 构建身份 | 从 Figma+EX 打开本地开发插件 | 顶栏必须显示与 `plugin/ui.html` 一致的当前指纹；当前生成值为 `DEV-4444AE532158`，任何正式宿主证据必须绑定实际打开的准确指纹 |
| 单击/首拖 | 单击选中；未选中内容直接拖动 | 同一手势归内容；不得被舞台抢走或无响应 |
| 普通移动 | 满屏内容拖动；缩小后再移动内容框 | 满屏时来源图平移；缩小后框与像素同步移动 |
| 普通缩放 | 拖四边/四角控制点 | 控制框与最终像素同边，旋转四角不越出物理开口 |
| 双击/裁切 | 双击进入，移动整框，边/角缩放，取消与完成 | 来源图在裁切中保持静止；取消回滚；完成退出 |
| 删除/历史 | 选中内容后 Backspace/Delete；Command-Z；Command-Shift-Z/Command-Y | 删除后回到无内容初始状态；撤销/重做可逆；选中态随快照恢复 |
| 卡片悬停 | 反复移入/移出样机卡片 | 每次进入只采样一次随机左/右倾斜；视觉层旋转；外层热区固定；不跟随鼠标位置 |
| 极限裁切 | 四个样机均在 300% 把裁切框拖向物理边界 | 框停在物理开口内；框外用户像素为 0 |
| 自由透视 | 笔记本角点先向外、再向内、再极限向外 | 越界被拒绝或钳制，向内有效，最终点位于物理开口 |
| 舞台导航 | 空白区、Space 或中键拖动 | 只改变舞台视图，不改变内容几何 |
| 复位/切换 | 改动后复位并切换四个样机 | 恢复默认内容、透视和舞台状态，无旧临时态残留 |
| Figma 写回 | 点击“粘贴到画布” | 成功回执；新增图层尺寸与输出画布一致 |
| 最终像素门禁 | 四个样机调用真实 `renderComposite()` 并扫描最终位图 | 框内有用户像素；投影框外用户像素严格为 0 |
| 工程门禁 | 构建一致、语法、testing/production 目录、全量测试、diff | 所有命令必须以当前代码真实通过；不复用旧计数 |
