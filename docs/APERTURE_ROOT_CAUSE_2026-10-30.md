# 手机样机可见孔径越界：根因与修复证据

> 历史说明：本文记录 renderer 2.2.0 / schema v3 对“内容越过物理边框”的修复。2026-10-30 后续又发现 v3 的精确孔径会遗漏原图孔径外 1–6px 的栅格软边，已由 renderer 2.3.0 / schema v4 的独立接缝覆盖层取代；当前结论见 `SEAM_ROOT_CAUSE_2026-10-30.md`。

日期：2026-10-30  
渲染器：2.2.0  
目录规范：schema v3

## 结论

问题主要来自插件与目录的几何模型，不是用户画面本身：旧模型用同一组 `screen.quad` 和一个偏小的圆角比例同时承担内容映射、真实可见孔径与接缝补边；渲染时又把 `bleed` 扩张后的四边形用作可见遮罩。结果是内容被允许进入物理边框，圆角看起来像被画面撑破。

## 像素证据

对两张原始样机的绿色内屏像素进行阈值分割，再把倾斜样机反投影到标准屏幕平面，拟合圆角矩形：

- 岩石手机：拟合边界为 `x=554…893`、`y=154…886`、圆角半径约 `41px`，平均边界误差 `0.054px`；圆角比例约 `0.12`。旧目录是 `x=556…892`、`y=154…884`、圆角比例 `0.06`。
- 支架手机：在 800px 标准屏幕平面上的最佳半径为 `96px`，即圆角比例 `0.12`；旧目录为 `0.055`。
- 两款手机旧圆角只达到真实曲率的约一半；旧渲染还把 `bleed=4` 加到可见遮罩上，使越界进一步扩大。

## 架构修复

1. `screen.quad` 只负责内容映射与编辑坐标。
2. `screen.aperture.quad` 与 `screen.aperture.cornerRadii` 独立描述物理可见开口。
3. `screen.bleed` 只在精确孔径下方做隐藏补边，禁止扩大可见遮罩。
4. 圆角支持四角独立比例，透视前在标准屏幕平面生成矢量孔径，再投影到样机。
5. 目录升级到 schema v3 / `static-screen-v3` / renderer 2.2.0；缺少独立孔径的数据不能通过校验。
6. 质检台增加“可见孔径与四角曲率”自动门禁，旧批准报告在渲染器或条目变化后自动失效。

## 验收

- 四个样机：8/8 自动检查、4/4 测试图、5 项人工检查通过。

- 1100×760 与 1640×1260 视口无页面溢出。
