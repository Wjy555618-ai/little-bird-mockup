# 插件回归纠正决定（2026-10-31）

决定人：Wang Zhentao

## 用户证据

决定人在真实 Figma 插件中提供了六张截图，分别证明：

1. 手机底部出现紫色/粉色角块，用户画面与物理屏幕边界不一致；
2. 样机卡片鼠标移入后剧烈旋转和抖动；
3. 裁切单边时另一轴也变化；
4. 裁切模式外层画布出现与真实画布不一致的圆角；
5. 旧 QA 放行了紫色角块与孔径泄漏；
6. 没有用户画面时显示了未经决定人提供或批准的蓝紫示例界面。

## 决定

决定人要求从插件整体、代码结构和大厂工程标准出发纠正根因，禁止继续局部打补丁。旧通过计数和旧构建不能覆盖真实回归证据。

## 不可移动约束

- 卡片悬停不得改变命中几何。
- 裁切单边只能改变对应轴并固定对边。
- 裁切框、物理孔径和外层画布不得混用圆角。
- 默认状态不得生成未经授权的界面内容。
- QA 必须验证屏幕内容来源和最终像素泄漏，不能只验证“不是绿幕”。
- 修正后的五个素材必须创建新 revision，经决定人视觉批准后才能进入技术 QA 和正式库。
- 本轮不执行 GitHub、Netlify、Figma Community 或其他外部发布。
