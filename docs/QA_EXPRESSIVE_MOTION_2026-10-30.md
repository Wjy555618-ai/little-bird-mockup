# 受控交互动效 QA（2026-10-30）

## 本轮目标

- 样机卡片每次鼠标移入时随机向左或向右扭转几度，但同一次悬停期间不重算、不抖动、不增加悬停描边。
- “全部 / 相似”使用同一个状态底板滑动切换。
- 分类从原生 `select` 替换为可控的自定义 `listbox`，带弹出、收起和箭头旋转过渡。
- 样机切换采用独立的双向高斯模糊曲线：280ms 进入 24px 强模糊，模糊阶段最少保持 380ms，再用 320ms 恢复清晰；不使用突然放大或瞬时跳变。
- 样机选中、名称、最近使用和预览作为一次事务提交：必须等全部图片成功后才切换，失败时原样机完整保留。

## 功能与动效验证

| 项目 | 验证方式 | 结果 |
| --- | --- | --- |
| 卡片随机方向 | 对同一非选中卡片执行 12 次“移入—停留—移出” | 同时出现左右方向，角度范围 -2.67° 至 +2.61° |
| 悬停稳定 | 每次落定后分两次读取变换角度 | 最大停留漂移 0° |
| 卡片内部鼠标移动 | 鼠标横向穿过卡片的 9 个采样点 | CSS 角度变量全程保持同一值 |
| 悬停描边 | 比较移入前后非选中卡片 `border-color` | 前后均为透明 |
| 全部 / 相似 | 真实点击后在 70ms 和 310ms 取样 | 状态底板从 0px 经 108.81px 移至 129.5px，并能返回全部 |
| 分类弹层 | 真实点击，70ms 取样，选择“手机”，再用键盘恢复“全部分类” | 中段透明度 0.47，过渡后 1；标签、筛选结果、ARIA 状态同步 |
| 清晰 → 高斯模糊 | 缓存资产真实点击，浏览器内每 30–40ms 连续取样 | 使用 `cubic-bezier(.24, .72, .2, 1)` 进入，取样观测到 `23.61 → 23.96 → 24px`，全程保留 24px 强高斯模糊 |
| 渲染热路径 | 对比首次打开新样机的主线程取样 | 将透视区域的逐像素多边形判断改为逐扫描线边界，实测首次切换从约 1.27s 降到 0.805s，缩短约 36.6% |
| 高斯模糊 → 清晰 | 重绘完成后继续每 30–40ms 取样 | 退出曲线为 `24 → 17.00 → 5.76 → 2.70 → 0.91 → 0.37 → 0.075 → 0.015 → 0px`，最终恢复 `opacity: 1` |
| 资源加载失败 | 将“支架手机”基础图定向替换为 404 故障资源 | 右侧画布尺寸、名称和左侧 active 卡片都保持“工作室显示器”，仅显示一次“已保留当前样机”提示 |
| 素材预解码与缓存 | 加载完成后轮询图片请求与响应头 | 四张基础图在空闲时预加载/预解码；带修订号的 PNG 返回 `max-age=31536000, immutable`，清单仍为 `no-store` |
| 连续快速切换 | 70ms 间隔连续点击两个样机 | 旧请求不会清理新请求的状态，最终样机正确，模糊恢复为 `blur(0px)` |
| 退出途中再次切换 | 模糊已降至 1.73px 时点击另一样机 | 从当前帧平滑转回 10.79px，不闪回清晰帧，最终正确完成新样机 |
| 减少动效 | `prefers-reduced-motion: reduce` 的 900×700 环境 | 分段、弹层过渡均为 0s，功能仍可用 |
| 小窗口布局 | 900×700 整体截图与区域边界检查 | 无页面横向或纵向滚动，左侧库、预览区和底部操作区均完整可见 |
